# AChE-1EVE-Inhibitor-Discovery-Docking-ADMET-and-MD-Simulation
An end-to-end computational drug discovery pipeline evaluating small-molecule inhibitors against Acetylcholinesterase (PDB ID: 1EVE). The repository spans structural preparation, quality validation (PROCHECK/ERRAT), AutoDock Vina screening, redocking RMSD validation, ADMET pharmacokinetic profiling, and MD simulations.
